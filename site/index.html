Download the installer

The installer works on Windows 7 to 11 and adds the Microsoft runtimes it needs.

Prefer no setup? Every release also has two portable zips, one for Windows 10 / 11 and one for Windows 7 SP1: extract the folder and start BUSMASTER.exe.

  • Windows 10 or 11, or Windows 7 SP1.
  • Microsoft Visual C++ 2013 Redistributable (x86): the installer adds it; with a portable zip, BUSMASTER-NG tells you if it is missing (most PCs already have it).
  • The driver of your CAN / LIN interface, from its manufacturer.
  • Node simulation only: MinGW, see the wiki page Node simulation.

What is different from BUSMASTER 3.2.2

  • Built with Visual Studio 2022; runs on Windows 7 to 11.
  • DBC databases load directly (CAN → Load DBC), and the DBC ↔ DBF converters are fixed.
  • Message window and Signal Watch show value descriptions of signals again.
  • Settings kept apart from earlier versions: install it next to BUSMASTER 3.2.2.
  • Configurations of BUSMASTER 3.2.x open unchanged.

About the project

BUSMASTER was conceived, designed and built by Robert Bosch Engineering and Business Solutions (RBEI), and became a joint project of RBEI and ETAS GmbH. Its last release, 3.2.2, dates from 2017: see the original project page.

BUSMASTER-NG is an independent community project that keeps it alive. It is not affiliated with, endorsed by or supported by ETAS GmbH or Robert Bosch GmbH. The copyright notices of the original authors are kept in the source files.

Maintainer: bigt92 (teoCLMR). Fix a bug, add a feature or test a driver on real hardware, and your name goes into the Hall of Madness.

Thanks to CLIMER, for always backing my crazy ideas, this one included. BUSMASTER-NG is a community project, not a CLIMER product: please report problems on GitHub.
